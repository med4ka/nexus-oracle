## ⚡ System Capabilities
* **Command Palette (`Ctrl+K`):** Omni-search navigation for instant system overrides, routing, and protocol access.
* **Root Hacker Terminal (`Ctrl+~`):** Hidden developer console featuring matrix-style rain canvas and simulated glitch rendering.
* **Ghost Sockets:** Real-time sonar interception of massive on-chain Whale transactions and A.I. anomaly detection.
* **Whale Radar & Mempool Visualizer:** Deep web scanning for pending block transactions and liquidity routing.
* **Oracle A.I. Assistant:** Context-aware market intelligence chatbot integrated directly into the HUD.
* **The Degen Vault:** Live market sentiment tracking and volatility indicators for altcoins.

## 🛠️ Monorepo Architecture
This repository is structured as a Monorepo, unifying the client interface and the predictive engine:
- `/nexus-oracle-frontend` — The Next.js client featuring heavy Framer Motion animations, Chart.js integrations, and custom hooks.
- `/nexus-core-system` — The backend API handling predictive logic, simulated spikes, state overriding, and system purging protocols.
